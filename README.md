## Featured Project: Linux Terminal Field Guide

A hands-on guide to the Linux command line for developers. It is written for Debian/Ubuntu-style systems.

**Repository:** [link to the guide's repo or folder]

**What it covers**

| Area | Topics |
| --- | --- |
| Navigation and files | `pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `less`, `head`, `tail`, `find`, `grep`, `man` |
| Permissions | `chmod`, `chown`, `sudo`, the Unix permission model |
| System health | `df`, `free`, `uptime`, `ps` |
| Processes and logs | `kill`, `Ctrl+C`, background jobs, `tail -f` |
| Shell productivity | Pipes, redirection, command history, tab completion |
| Packages | `apt` |
| Safety | Reading a command before running it, destructive-command pitfalls such as `rm -rf /`, using `sudo` deliberately |
